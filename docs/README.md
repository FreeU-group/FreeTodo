# Docs Index

This folder is organized by document purpose so root-level materials and existing docs are easier to browse.

## Structure

- `architecture/`: architecture designs, module designs, technical diagrams, and audio pipeline docs
- `guides/`: setup, deployment, and end-to-end usage guides
- `plans/`: feature plans, research notes, change logs, and backlog-style tracking docs
- `reports/`: review and audit reports
- `examples/`: sample payloads and supporting example files
