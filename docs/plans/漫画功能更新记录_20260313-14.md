## 一、核心架构升级：从「单图」到「多分镜漫画」

### 1. Prompt 升级为漫画分镜页布局

- **提交：** `f9bbbbbe` — 03-13 11:52
- **改动文件：** `lifetrace/services/diary_illustration_service.py`

将 LLM 的 system prompt 从"生成一张温暖日系单幅插画"升级为"生成多格漫画分镜页"：

- 要求输出 3-6 个漫画分格（comic panels），按时间顺序排列
- 描述整体布局为纵向 manga page
- 每个 panel 包含人物动作、表情、环境、对话气泡
- 同一主角贯穿所有分格，保持外貌一致性
- max_tokens 从 300 提升到 500

### 2. 多分镜独立生成（核心重构）

- **提交：** `ec1a03c5` — 03-13 12:10
- **改动文件：** 4 个文件，+167/-187 行

**后端 `diary_illustration_service.py`：**

- LLM 不再生成单段 prompt，而是输出 **JSON 数组**，每个元素包含 `scene`（场景标题）和 `prompt`（英文 prompt）
- 新增 `_build_scene_prompts()` 方法，解析 LLM 返回的 JSON 数组，拆分为 2-5 个场景
- 每个场景的 prompt 100-150 词，max_tokens 从 500 提升到 1200
- 将 `_call_banna2()` 重命名为 `_call_gemini()`，逐个场景调用 Gemini API 生成独立图片
- 图片保存命名从 `{date}.png` 改为 `{date}_1.png`, `{date}_2.png` ...
- 新增 `_clean_date_images()` 方法，重新生成前先清理旧图
- `get_illustration_paths()` 返回按序号排序的多张图片路径列表
- 返回结构从 `{ok, path, prompt}` 改为 `{ok, count, paths}`

**前端 `DiaryEditor.tsx` / `DiaryPanel.tsx`：**

- 去掉了单图展示，改为**可滚动画廊**，展示多张分镜漫画
- 增加时间戳防止图片缓存

## 总结对比

| 维度 | 升级前 | 升级后 |
|------|--------|--------|
| 图片数量 | 1 张 | 2-5 张（按场景拆分） |
| Prompt 策略 | 单段描述 | JSON 数组，每场景独立 prompt |
| 文件命名 | `{date}.png` | `{date}_1.png` ~ `{date}_5.png` |
| UI 展示 | 独立插画区域 | 合并到 AI Tab，可滚动画廊 |
| 生成触发 | 单独按钮 | 与 AI 文字并发生成 |
| 日期切换 | 手动刷新 | 自动加载已有结果 |
| 架构 | `lifetrace/` 旧目录 | `server/` 新架构 + 热重载 cron |
