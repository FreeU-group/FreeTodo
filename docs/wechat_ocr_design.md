# 微信 OCR 结构化解析机制（仓库实现说明）

本文档沉淀本仓库中微信聊天界面 OCR 的设计与实现思路，聚焦“如何设计与如何分层”，不包含任何代码片段。

## 目标与范围

该机制用于从桌面微信窗口中提取可理解的聊天文本，并尽可能结构化为“会话类型 + 会话名称 + 多条消息 + 说话人归属”。

适用范围：

- 桌面端微信窗口的前台截图。
- 以“聊天列表 + 聊天面板”布局为前提的界面版本。
- 需要在本地感知链路中低成本、低延迟地获取文本。

## 总体流程概览

1. 识别前台窗口是否为微信。
2. 捕获窗口图像并做基础质量过滤。
3. 从窗口中裁剪出聊天面板的 ROI（去掉左侧联系人列表）。
4. 对聊天面板做 OCR。
5. 根据 UI 结构把 OCR 结果拆分为标题区与消息区。
6. 识别私聊/群聊与会话名称。
7. 对消息行进行说话人归属与昵称关联。
8. 输出结构化文本与必要的元数据。

## 窗口识别与路由

设计目的：只对目标应用执行高成本 OCR，避免误采集。

实现思路：

- 通过进程名与窗口标题关键词判断是否为微信。
- 若无法匹配则直接跳过，不进入 OCR 流程。

## 窗口捕获与图像质量过滤

设计目的：降低空白帧、最小化无效 OCR 计算。

实现思路：

- 捕获当前前台窗口图像。
- 对图像做基础统计，若画面接近空白或噪声不足，则跳过。

## 聊天面板 ROI 裁剪

设计目的：剔除左侧联系人栏与无关 UI，提高 OCR 精度与速度。

关键设计点：

- 优先检测聊天面板与联系人栏之间的“垂直分割线”。
- 通过对垂直方向的对比度变化进行扫描，找到稳定的分割位置。
- 若分割线检测失败，则使用“背景颜色对齐”或“比例回退”来估算聊天面板起始位置。
- 裁剪时保留一小段左侧边距，避免顶部标题被裁剪。

## 主题识别与颜色先验

设计目的：为“气泡归属”和“布局检测”提供稳健的颜色参考。

实现思路：

- 在裁剪后的聊天面板中检测主题（深色/浅色）。
- 主题决定聊天背景色与气泡颜色的参考值与容忍度。

## 标题区与消息区分割

设计目的：区分会话标题与具体消息行，保证会话识别准确。

实现思路：

- 在聊天面板顶部区域扫描细薄的水平分割线。
- 分割线之上视为标题区，之下视为消息区。
- 若分割线检测失败，使用固定高度比例作为回退边界。

## 会话类型与名称识别

设计目的：判断私聊/群聊，并提取会话名称。

实现思路：

- 将标题区 OCR 行拼接为标题文本。
- 若标题末尾带“成员数后缀”（如括号数字），判定为群聊。
- 群聊名称去除成员数后缀；私聊名称直接使用标题文本。

## 消息行筛选与排序

设计目的：对 OCR 输出进行去噪、排序、可用性过滤。

实现思路：

- 只保留消息区内、置信度足够的 OCR 行。
- 按垂直方向顺序排序，保持消息时间序。

## 说话人归属与昵称关联

设计目的：在群聊中识别消息发送者，在私聊中区分“我/对方”。

实现思路：

- 对每条消息行，先用气泡颜色判断左右归属（我/对方）。
- 若颜色判断失败，使用消息位置相对聊天面板中心进行回退判断。
- 群聊中识别“昵称行”并绑定到其后最近的消息行。
- 私聊中若无法识别昵称，则统一归为“对方”。

昵称行识别规则（设计意图）：

- 通常位于消息正文上方、字体更小、行高更低。
- 文本长度较短、宽度较窄。
- 与下一行消息的垂直间距较小。

## 结构化输出

输出内容包括：

- 会话类型（私聊/群聊）。
- 会话名称与联系人名称（如适用）。
- 多条消息，每条包含文本与说话人归属。
- 关键分割线位置与主题信息（用于调试与再处理）。

当结构化解析失败或结果为空时，退化输出为 OCR 纯文本，确保链路连续可用。

## 鲁棒性与回退策略

该设计强调“尽量结构化、不能结构化则安全回退”：

- 任何单步失败都不影响整体 OCR 输出。
- 多处采用比例或位置的回退策略。
- 在低质量帧或无明显 UI 特征时，优先保证稳定性与低误判。

## 主要限制与注意事项

- 强依赖桌面微信的经典布局；改版或缩放可能影响分割线检测。
- 群聊判断基于标题格式，若标题被遮挡或 OCR 误识别会产生误判。
- 颜色采样对主题与显示器色彩有一定敏感度。

## 相关模块位置

本机制涉及的主要模块：

- `client/sensor.py`：OCR 触发与结构化解析入口。
- `client/proactive_ocr/router.py`：窗口识别与路由。
- `client/proactive_ocr/roi.py`：ROI 提取入口。
- `client/proactive_ocr/priors/wechat.py`：微信先验与分割线/主题检测。
- `client/proactive_ocr/wechat_message_parser.py`：消息结构化解析。
