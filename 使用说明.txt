FreeTodo Windows 单文件脚本使用说明

这个说明是给小白用户写的。
如果你只想赶紧跑起来，请先看前面的“简略版”。
如果你想知道每一步到底发生了什么，再看后面的“详细版”。


====================
一、简略版（先看这个）
====================

你现在有两个脚本：

1. setup-and-start-all-chore-liji-thesis.cmd
   作用：一键安装 + 一键启动

2. stop-all-chore-liji-thesis.cmd
   作用：一键停止全部服务


如果你是第一次用：

1. 新建一个空文件夹
2. 把 setup-and-start-all-chore-liji-thesis.cmd 放进去
3. 双击这个脚本
4. 等它自己安装、自己启动
5. 浏览器自动打开后，就可以开始用 FreeTodo 了


如果你已经装过了：

1. 直接再次双击 setup-and-start-all-chore-liji-thesis.cmd
2. 它会自动跳过已经安装过的内容
3. 如果服务已经在运行，它也会自动跳过重复启动


如果你想关闭：

1. 把 stop-all-chore-liji-thesis.cmd 放到同一个文件夹里
2. 双击 stop-all-chore-liji-thesis.cmd
3. 它会自动把后台服务都关掉


一句话理解：

- 想启动，就双击 setup-and-start-all-chore-liji-thesis.cmd
- 想停止，就双击 stop-all-chore-liji-thesis.cmd


====================
二、详细版
====================


1. 这两个脚本分别是干什么的？

setup-and-start-all-chore-liji-thesis.cmd
- 用来一键安装并启动 FreeTodo
- 默认使用分支：chore/liji/thesis

stop-all-chore-liji-thesis.cmd
- 用来一键停止 FreeTodo 相关服务
- 默认使用分支：chore/liji/thesis


2. 启动脚本会帮你做什么？

启动脚本会自动完成下面这些事情：

- 检查电脑里有没有 Git
- 检查电脑里有没有 Python
- 检查电脑里有没有 Node.js
- 检查电脑里有没有 uv
- 检查电脑里有没有 pnpm
- 如果没有，它会尽量自动安装
- 自动下载对应分支的 FreeTodo 代码
- 自动安装 server、client、frontend 的依赖
- 自动启动下面 4 个东西：
  1) Backend
  2) AgentOS
  3) Frontend
  4) Sensor

其中 Sensor 非常重要。
它是本机感知器。
如果没有 Sensor，本机的截图感知、OCR 感知等功能会缺失，很多能力就不完整。


3. 第一次使用，应该怎么做？

推荐步骤：

1. 在电脑任意位置新建一个空文件夹
2. 把 setup-and-start-all-chore-liji-thesis.cmd 下载到这个空文件夹里
3. 双击运行它
4. 脚本会自动开始：
   - 装环境
   - 拉代码
   - 装依赖
   - 启动服务
5. 完成后会自动打开浏览器

这时候你就可以开始使用了。


4. 第二次以后怎么用？

第二次以后，通常更简单：

1. 再次双击 setup-and-start-all-chore-liji-thesis.cmd
2. 脚本会自动检查：
   - 已安装的依赖直接跳过
   - 已运行的服务直接跳过
   - 没运行的服务再启动起来

也就是说，你不需要自己判断“要不要重装”“要不要重启”。
脚本会帮你处理。


5. 停止脚本怎么用？

如果你不想让 FreeTodo 继续在后台运行：

1. 双击 stop-all-chore-liji-thesis.cmd

它会尝试停止这些服务：

- Backend
- AgentOS
- Frontend
- Sensor

同时还会清理：

- pid 记录文件
- 前端 dev lock 文件


6. 脚本会把代码下载到哪里？

如果脚本所在位置本身不是 FreeTodo 仓库目录，
它会在当前文件夹下自动创建一个代码目录，目录名通常类似：

FreeTodo-chore-liji-thesis

所以一个常见的使用方式是：

- 你自己先建一个空文件夹
- 把脚本放进去
- 让脚本自己把项目下载进去


7. 如果我想指定别的分支怎么办？

默认分支是：

chore/liji/thesis

但你也可以手动指定分支。

例如：

setup-and-start-all-chore-liji-thesis.cmd -Branch main
setup-and-start-all-chore-liji-thesis.cmd -Branch dev
setup-and-start-all-chore-liji-thesis.cmd -Branch chore/liji/thesis

停止脚本也一样可以带参数：

stop-all-chore-liji-thesis.cmd -Branch chore/liji/thesis


8. 如果脚本检测到已经安装过，会怎么样？

它会自动跳过安装。

也就是说：

- 已安装的依赖，不会重复安装
- 已运行的服务，不会重复启动

这就是为什么你可以放心多次双击启动脚本。


9. 如果脚本已经启动过服务，再次运行停止脚本会怎么样？

它会：

- 优先根据脚本自己记录的 pid 去停服务
- 如果找不到 pid，也会尽量按进程特征去找对应服务
- 找到就停止
- 找不到就跳过


10. 你真正需要记住的只有两件事

启动：
- 双击 setup-and-start-all-chore-liji-thesis.cmd

停止：
- 双击 stop-all-chore-liji-thesis.cmd
